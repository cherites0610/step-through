寫出兩個函數的遞迴關係式並求出時間複雜度（n 為 2 的次方）。

```
g(n):
    if n <= 1: return 1
    s = 0
    for i = 1 to n: s = s + 1
    return g(n/2) + g(n/2) + s

h(n):
    if n <= 1: return 1
    s = 0
    for i = 1 to n: s = s + 1
    t = h(n/2)
    return t + t + s
```

<Solution>

- **g：T(n) = 2T(n/2) + Θ(n) → Θ(n log n)。** 遞迴呼叫了兩次。主定理：n^(log₂ 2) = n，f(n) = Θ(n)，情況 2。
- **h：T(n) = T(n/2) + Θ(n) → Θ(n)。** 只呼叫一次，把結果存起來用兩次。主定理：n^(log₂ 1) = 1，f(n) = n 大了多項式倍，而且 1·(n/2) ≤ (1/2)·n，情況 3。也可以直接加總：n + n/2 + n/4 + … ＜ 2n。

兩個函數的回傳值相同，但 g 多做了大量重複計算。

</Solution>

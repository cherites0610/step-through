下列敘述哪些正確？（複選）

(A) <M t="2^{n+1} = O(2^n)" />

(B) <M t="2^{2n} = O(2^n)" />

(C) <M t="n \log n = \Omega(n)" />

(D) <M t="\log_2 n = \Theta(\log_{10} n)" />

(E) <M t="n^3 = O(n^2 \log n)" />

<Solution>

**答案：(A)、(C)、(D)。**

判斷 <M t="f = O(g)" /> 的方法：試著找常數 <M t="c" /> 和 <M t="n_0" />，使 <M t="n \ge n_0" /> 時 <M t="f(n) \le c \cdot g(n)" />。找得到就對；若不管 <M t="c" /> 多大都會在某個 <M t="n" /> 失敗，就錯。

- **(A) 對。** 要 <M t="2^{n+1} \le c \cdot 2^n" />。左邊就是 <M t="2 \cdot 2^n" />，所以取 <M t="c = 2" />，對每個 <M t="n \ge 1" /> 都成立（<M t="n_0 = 1" />）。
- **(B) 錯。** 要 <M t="2^{2n} = 4^n \le c \cdot 2^n" />。兩邊除以 <M t="2^n" />，變成 <M t="2^n \le c" />。但 <M t="2^n" /> 會無限長大，不管 <M t="c" /> 多大，只要 <M t="n > \log_2 c" /> 就失敗。指數的**底數**不同，就不是同一級。
- **(C) 對。** 這是 <M t="\Omega" />，要找 <M t="c" /> 和 <M t="n_0" /> 使 <M t="n \log_2 n \ge c \cdot n" />。兩邊除以 <M t="n" />，變成 <M t="\log_2 n \ge c" />。取 <M t="c = 1" />，就需要 <M t="\log_2 n \ge 1" />，也就是 <M t="n \ge 2" />，所以 <M t="n_0 = 2" />。
- **(D) 對。** 換底公式：<M t="\log_2 n = \dfrac{\log_{10} n}{\log_{10} 2} \approx 3.32 \log_{10} n" />。兩者只差常數倍，上界取 <M t="c = 3.33" />、下界取 <M t="c = 3.32" />（<M t="n_0 = 2" />）即可。對數的**底數**不影響成長率。
- **(E) 錯。** 要 <M t="n^3 \le c \cdot n^2 \log n" />。兩邊除以 <M t="n^2" />，變成 <M t="n \le c \log n" />。但 <M t="n / \log n" /> 會無限長大（<M t="n" /> 比 <M t="\log n" /> 長得快），所以不管 <M t="c" /> 多大最後都失敗。

</Solution>

下列敘述哪些正確？（複選）

(A) <M t="2^{n+1} = O(2^n)" />

(B) <M t="2^{2n} = O(2^n)" />

(C) <M t="n \log n = \Omega(n)" />

(D) <M t="\log_2 n = \Theta(\log_{10} n)" />

(E) <M t="n^3 = O(n^2 \log n)" />

<Solution>

**答案：(A)、(C)、(D)。**

- (A) 對。<M t="2^{n+1} = 2 \cdot 2^n" />，取 <M t="c = 2" /> 即可。
- (B) 錯。<M t="2^{2n} = 4^n" />，<M t="4^n / 2^n = 2^n \to \infty" />，找不到常數 <M t="c" />。指數的**底數**不同就不是同一級。
- (C) 對。<M t="n \ge 2" /> 時 <M t="n \log_2 n \ge n" />，取 <M t="c = 1" />、<M t="n_0 = 2" />。
- (D) 對。<M t="\log_2 n = \log_{10} n / \log_{10} 2" />，只差常數倍。對數的**底數**不影響成長率。
- (E) 錯。<M t="\dfrac{n^3}{n^2 \log n} = \dfrac{n}{\log n} \to \infty" />。

</Solution>

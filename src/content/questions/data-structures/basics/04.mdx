下面的程式中，最內層的敘述共執行幾次？用 <M t="\Theta" /> 表示。

```
for i = 1 to n
    for j = i + 1 to n
        for k = j + 1 to n
            x = x + 1
```

<Solution>

**<M t="\dfrac{n(n-1)(n-2)}{6}" /> 次，<M t="\Theta(n^3)" />。**

三個迴圈變數滿足 <M t="1 \le i < j < k \le n" />，而且每一組 <M t="(i, j, k)" /> 恰好被執行一次。所以次數就是「從 <M t="1 \ldots n" /> 中選 3 個不同的數」的組合數：

<M d t="\binom{n}{3} = \frac{n(n-1)(n-2)}{6} = \Theta(n^3)" />

把巢狀迴圈看成「選出幾個遞增的索引」，常常比一層一層加總快。

</Solution>

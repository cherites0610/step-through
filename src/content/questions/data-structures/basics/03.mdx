下面的迴圈本體共執行幾次（<M t="n \ge 1" />）？時間複雜度是多少？

```
i = 1
while i < n
    i = i * 2
```

<Solution>

**<M t="\lceil \log_2 n \rceil" /> 次，<M t="\Theta(\log n)" />。**

<M t="i" /> 依序是 1, 2, 4, 8, …。第 <M t="k" /> 次執行本體之前 <M t="i = 2^{k-1}" />，當 <M t="i \ge n" /> 時停止。

- <M t="n = 1" />：一開始就不成立，0 次（<M t="\lceil \log_2 1 \rceil = 0" />）
- <M t="n = 5" />：<M t="i = 1, 2, 4" /> 時執行，共 3 次（<M t="\lceil \log_2 5 \rceil = 3" />）
- <M t="n = 8" />：<M t="i = 1, 2, 4" /> 時執行，共 3 次（<M t="\log_2 8 = 3" />）

變數每次乘以常數，次數就是 <M t="\log" />。

</Solution>

用展開法求出下列遞迴關係式的**精確**解。

(a) 河內塔：T(1) = 1，T(n) = 2T(n − 1) + 1

(b) T(1) = 1，T(n) = T(n − 1) + n

<Solution>

**(a) T(n) = 2ⁿ − 1。**

```
T(n) = 2T(n−1) + 1
     = 2[2T(n−2) + 1] + 1  = 4T(n−2) + 2 + 1
     = 8T(n−3) + 4 + 2 + 1
     = …
     = 2^(n−1)·T(1) + 2^(n−2) + … + 2 + 1
     = 2^(n−1) + (2^(n−1) − 1)
     = 2^n − 1
```

驗算：T(2) = 3、T(3) = 7，與 2ⁿ − 1 相符。

**(b) T(n) = n(n + 1) / 2。**

T(n) = n + (n − 1) + … + 2 + T(1) = n + (n − 1) + … + 2 + 1 = n(n + 1) / 2 = Θ(n²)

這一題不是「除以 b」的形式，不能用主定理。

</Solution>

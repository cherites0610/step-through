下面的程式中，`x = x + 1` 共執行幾次？用 <M t="\Theta" /> 表示時間複雜度。

```
for i = 1 to n
    for j = i to n
        x = x + 1
```

<Solution>

**<M t="\dfrac{n(n+1)}{2}" /> 次，<M t="\Theta(n^2)" />。**

<M t="i = 1" /> 時內層從 1 跑到 <M t="n" />，共 <M t="n" /> 次；<M t="i = 2" /> 時 <M t="n-1" /> 次；……；<M t="i = n" /> 時 1 次（見觀念說明的圖 1-1）。

<M d t="n + (n-1) + \cdots + 1 = \frac{n(n+1)}{2} = \Theta(n^2)" />

</Solution>

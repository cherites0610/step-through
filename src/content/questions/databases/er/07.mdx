某 ER 圖有下列元素：

- 強實體 A(a1, a2)、B(b1, b2)、C(c1, c2)，鍵分別是 a1、b1、c1；c2 是**多值屬性**。
- 弱實體 D，部分鍵 d1，另有屬性 d2；識別擁有者是 A。
- R1：A 與 B 是 1:N（A 是 1 的一端）。
- R2：B 與 C 是 M:N，關係有屬性 r。
- R3：A 與 C 是 1:1，C 是完全參與、A 是部分參與。

(a) 轉成關聯綱要，最少需要幾個表？

(b) 寫出每個表的欄位，標出主鍵與外鍵。

<Solution>

**(a) 6 個。**

**(b)**

- A(<u>a1</u>, a2)
- B(<u>b1</u>, b2, a1)，a1 → A
- C(<u>c1</u>, a1)，a1 → A
- D(<u>a1, d1</u>, d2)，a1 → A
- R2(<u>b1, c1</u>, r)，b1 → B，c1 → C
- C_c2(<u>c1, c2</u>)，c1 → C

照轉換步驟逐項處理：

1. 強實體 A、B、C 各一個表（3 個）。C 的多值屬性 c2 先不放。
2. 弱實體 D 一個表，主鍵是擁有者的主鍵 a1 加部分鍵 d1（第 4 個）。
3. R3 是 1:1，外鍵放在完全參與的 C：C 加 a1 → A。不用新表。
4. R1 是 1:N，外鍵放在 N 的 B：B 加 a1 → A。不用新表。
5. R2 是 M:N，開新表，主鍵是 (b1, c1)，屬性 r 放在這裡（第 5 個）。
6. 多值屬性 c2 開新表，主鍵是 (c1, c2)（第 6 個）。

1:1 與 1:N 的關係不需要新表，所以是 <M t="3 + 1 + 1 + 1 = 6" /> 個。

</Solution>

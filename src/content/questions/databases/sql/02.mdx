Course 的課名有：資料庫、資料結構、資料庫管理、計算機概論、管理資料學。下列條件各選出幾門課？哪一個敘述**錯誤**？

(A) `title LIKE '資料%'` 選出 3 門

(B) `title LIKE '%資料%'` 選出 4 門

(C) `title LIKE '資料_'` 選出 1 門

(D) `title LIKE '%管理'` 選出 2 門

<Solution>

**答案：(D)。**

`%` 代表任意長度（包含 0 個字）的字串，`_` 代表恰好一個字。

- **(A) 對。** 以「資料」開頭：資料庫、資料結構、資料庫管理，3 門。
- **(B) 對。** 任何位置含有「資料」：資料庫、資料結構、資料庫管理、管理資料學，4 門。
- **(C) 對。** 「資料」後面恰好一個字：只有資料庫。資料結構後面有兩個字，不符合。
- **(D) 錯。** 以「管理」結尾：只有資料庫管理，1 門。管理資料學的「管理」在開頭，不符合。

</Solution>

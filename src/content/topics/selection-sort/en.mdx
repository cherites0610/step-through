## What selection sort does

Each round, selection sort **selects the minimum** of the unsorted range and puts it at the front of that range.

1. Assume the first number of the range is the minimum.
2. Scan the rest from left to right, updating the minimum whenever a smaller value appears.
3. When the scan ends, swap the minimum with the first number of the range.
4. Shrink the range by one (the left cell is now sorted) and repeat until one number is left.

## How it differs from insertion and bubble sort

Selection sort always makes the same number of comparisons whatever the data, but very few swaps. Switch between the preset inputs and you will see comparisons stay at n(n − 1) / 2 while swaps never exceed n − 1.

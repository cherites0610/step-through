### 演算法與效能分析

**演算法**（algorithm）是解決問題的有限步驟。課本常列出它必須滿足的五個性質：

| 性質 | 意思 |
|---|---|
| 輸入（input） | 零個或多個由外部提供的資料 |
| 輸出（output） | 至少產生一個結果 |
| 明確性（definiteness） | 每一步都清楚、沒有歧義 |
| 有限性（finiteness） | 一定會在有限步之後結束 |
| 有效性（effectiveness） | 每一步都基本到可以用紙筆在有限時間內做完 |

「程式」不一定滿足有限性：作業系統本身就是一個不會主動結束的程式，所以它不是演算法。這是選擇題常見的陷阱。

分析一個演算法，看兩件事：

- **時間複雜度**：執行需要多少步，表示成輸入大小 <M t="n" /> 的函數。
- **空間複雜度**：除了輸入本身之外，還需要多少額外記憶體（變數、陣列、遞迴呼叫的堆疊）。

考試常要求**步驟計數**：算出某一行敘述被執行幾次。方法是由內往外，把每一層迴圈的次數加總。

```
for i = 1 to n
    for j = i to n
        x = x + 1
```

外層每換一個 <M t="i" />，內層的 <M t="j" /> 就從 <M t="i" /> 跑到 <M t="n" />，共 <M t="n - i + 1" /> 次：<M t="i = 1" /> 時 <M t="n" /> 次，<M t="i = 2" /> 時 <M t="n-1" /> 次，……，<M t="i = n" /> 時 1 次。把每一組 <M t="(i, j)" /> 畫成一格，執行過的格子剛好排成一個三角形：

<Figure no="1-1" caption="n = 6 時，第 i 列有 n − i + 1 個實心格。實心格的總數就是 x = x + 1 的執行次數。">
  <LoopTriangle />
</Figure>

所以總次數是

<M d t="\sum_{i=1}^{n} (n - i + 1) = n + (n-1) + \cdots + 1 = \frac{n(n+1)}{2}" />

最後一步是「1 加到 <M t="n" />」的公式：把這串數字正著寫一次、倒著寫一次再上下相加，每一對都是 <M t="n + 1" />，共 <M t="n" /> 對，所以兩倍的總和是 <M t="n(n+1)" />。

另一種常見的迴圈是「每次乘以 2」：

```
i = 1
while i < n
    i = i * 2
```

把每次檢查條件時 <M t="i" /> 的值列出來：第 1 次是 1，第 2 次是 2，第 3 次是 4，……，第 <M t="k" /> 次是 <M t="2^{k-1}" />。迴圈在 <M t="i \ge n" /> 時停下，所以本體執行的次數，就是「<M t="2^{k} \ge n" /> 的最小 <M t="k" />」，也就是 <M t="\lceil \log_2 n \rceil" />（<M t="n \ge 1" />）。例如 <M t="n = 5" />：<M t="i = 1, 2, 4" /> 時執行，<M t="i = 8" /> 時停止，共 3 次，而 <M t="\lceil \log_2 5 \rceil = 3" />。

看到變數每次被乘或除以一個常數，執行次數就跟 <M t="\log" /> 有關。

### 漸近符號

#### 為什麼需要漸近符號

精確的步驟數（例如 <M t="3n^2 + 5n + 7" />）既瑣碎，也不穩定：換一台電腦、換一個編譯器，每一步的時間就變了，常數也跟著變。我們真正關心的是 **<M t="n" /> 變大時，時間怎麼跟著長**。<M t="3n^2 + 5n + 7" /> 在 <M t="n" /> 很大時幾乎都是 <M t="3n^2" /> 在貢獻，而 <M t="3n^2" /> 和 <M t="n^2" /> 只差一個常數倍，所以我們說它「長得像 <M t="n^2" />」。漸近符號就是把這句話說精確的方法。

#### Big-O：上界

<M t="f(n) = O(g(n))" /> 想表達的是：「**<M t="n" /> 夠大之後，<M t="f(n)" /> 不會超過 <M t="g(n)" /> 的某個常數倍**。」這句話裡有兩個要我們自己挑的數字：

- **<M t="c" />（常數倍）**：允許 <M t="g" /> 乘上一個正的常數再來比。因為常數倍不影響成長率，所以 <M t="3n^2" /> 雖然比 <M t="n^2" /> 大，但只要取 <M t="c = 3" />，就不會超過 <M t="c \cdot n^2" />。
- **<M t="n_0" />（從哪裡開始算）**：只要求「<M t="n" /> 夠大之後」成立。<M t="n" /> 小的時候 <M t="f" /> 可以比 <M t="c \cdot g" /> 大，只要從 <M t="n_0" /> 開始，之後**每一個** <M t="n" /> 都不超過就好。

把兩個數字放進去，就是正式定義：

> **定義**：若存在常數 <M t="c > 0" /> 與 <M t="n_0" />，使所有 <M t="n \ge n_0" /> 都有 <M t="f(n) \le c \cdot g(n)" />，就記作 <M t="f(n) = O(g(n))" />。

證明 <M t="f(n) = O(g(n))" />，就是**親手找出一組 <M t="c" /> 和 <M t="n_0" />**，再說明它們真的成立。

圖 1-2 是一個例子：<M t="f(n) = n^2 + 6n + 10" />、<M t="g(n) = n^2" />，取 <M t="c = 2" />。<M t="n" /> 小的時候，<M t="f" /> 裡的 <M t="6n + 10" /> 讓它比 <M t="2n^2" /> 大；但 <M t="2n^2" /> 長得比較快，兩條曲線在 <M t="n_0 \approx 7.4" /> 交叉，之後 <M t="f" /> 就一直在下方。所以 <M t="c = 2" />、<M t="n_0 = 8" />（取一個大於交叉點的整數）就是一組答案。

  <BigODefinition />
</Figure>

#### 例：一步一步證明 3n² + 5n + 7 = O(n²)

**目標**：找出 <M t="c" /> 和 <M t="n_0" />，使 <M t="n \ge n_0" /> 時 <M t="3n^2 + 5n + 7 \le c \cdot n^2" />。

**想法**：把每一項都放大成 <M t="n^2" /> 的倍數，右邊就自然是「某個數乘 <M t="n^2" />」。只要 <M t="n \ge 1" />，就有 <M t="n \le n^2" /> 和 <M t="1 \le n^2" />，所以：

<M d t="\begin{aligned} 5n &\le 5n^2 && (\text{因為 } n \le n^2) \\ 7 &\le 7n^2 && (\text{因為 } 1 \le n^2) \\ 3n^2 + 5n + 7 &\le 3n^2 + 5n^2 + 7n^2 = 15n^2 \end{aligned}" />

**結論**：取 <M t="c = 15" />、<M t="n_0 = 1" />，所有 <M t="n \ge 1" /> 都滿足 <M t="3n^2 + 5n + 7 \le 15n^2" />，所以 <M t="3n^2 + 5n + 7 = O(n^2)" />。

<M t="c" /> 和 <M t="n_0" /> **不是唯一的**。如果想用比較小的 <M t="c = 4" />，就要求 <M t="3n^2 + 5n + 7 \le 4n^2" />，移項得 <M t="n^2 \ge 5n + 7" />：<M t="n = 6" /> 時 <M t="36 < 37" /> 不成立，<M t="n = 7" /> 時 <M t="49 \ge 42" /> 成立（之後也一直成立），所以 <M t="c = 4" />、<M t="n_0 = 7" /> 也是一組答案。<M t="c" /> 取得越小，通常 <M t="n_0" /> 就要越大。考試只要給出**任何一組**正確的 <M t="c" /> 和 <M t="n_0" /> 即可。

#### 反例：為什麼 n² ≠ O(n)

要說明 <M t="f(n) = O(g(n))" /> **不**成立，就要說明「**不管 <M t="c" /> 取多大，都找不到 <M t="n_0" />**」。

假設 <M t="n^2 \le c \cdot n" /> 對所有 <M t="n \ge n_0" /> 都成立。兩邊除以 <M t="n" />，得到 <M t="n \le c" />。但 <M t="c" /> 是固定的常數，只要取 <M t="n = c + 1" />（而且比 <M t="n_0" /> 大），就違反了。所以無論 <M t="c" /> 多大都失敗，<M t="n^2 \ne O(n)" />。

#### Ω 與 Θ：下界與「同一級」

**Ω（Big-Omega）** 是反過來的下界：<M t="n" /> 夠大之後，<M t="f(n)" /> **至少**是 <M t="g(n)" /> 的某個常數倍。

> **定義**：若存在常數 <M t="c > 0" /> 與 <M t="n_0" />，使所有 <M t="n \ge n_0" /> 都有 <M t="f(n) \ge c \cdot g(n)" />，就記作 <M t="f(n) = \Omega(g(n))" />。

例如 <M t="3n^2 + 5n + 7 \ge 3n^2" /> 對所有 <M t="n \ge 1" /> 都成立（後兩項都是正的），所以取 <M t="c = 3" />、<M t="n_0 = 1" />，得到 <M t="3n^2 + 5n + 7 = \Omega(n^2)" />。

**Θ（Big-Theta）** 是上下界同時成立：<M t="f(n) = \Theta(g(n))" /> 等於 <M t="f = O(g)" /> **而且** <M t="f = \Omega(g)" />。上面兩個例子合起來，就證明了 <M t="3n^2 + 5n + 7 = \Theta(n^2)" />：它被夾在 <M t="3n^2" /> 和 <M t="15n^2" /> 之間。

#### o 與 ω：嚴格的「比較慢」與「比較快」

<M t="O" /> 允許「一樣快」（例如 <M t="n^2 = O(n^2)" />）。如果要說「**嚴格**比較慢」，用小寫的 <M t="o" />。兩者定義只差一個地方：

- <M t="O" />：**存在一個** <M t="c" /> 使不等式成立（我們挑一個夠大的 <M t="c" /> 就好）。
- <M t="o" />：**對每一個** <M t="c > 0" />（不管多小）都成立，只是 <M t="n_0" /> 可以跟著 <M t="c" /> 改變。

「再小的常數倍都追不上」，就等於 <M t="f" /> 和 <M t="g" /> 的比值趨近於 0；<M t="\omega" /> 則是反過來，比值趨近於無限大。

| 符號 | 意思 | 用比值判斷 |
|---|---|---|
| <M t="f = O(g)" /> | <M t="f" /> 不會比 <M t="g" /> 長得快 | <M t="f/g" /> 不會趨向無限大 |
| <M t="f = \Omega(g)" /> | <M t="f" /> 至少和 <M t="g" /> 一樣快 | <M t="f/g" /> 不會趨向 0 |
| <M t="f = \Theta(g)" /> | 同一個成長率 | <M t="f/g" /> 趨向一個正的常數（或夾在兩個正常數之間） |
| <M t="f = o(g)" /> | <M t="f" /> 嚴格比 <M t="g" /> 慢 | <M t="f/g \to 0" /> |
| <M t="f = \omega(g)" /> | <M t="f" /> 嚴格比 <M t="g" /> 快 | <M t="f/g \to \infty" /> |

例如 <M t="n = o(n^2)" />，因為 <M t="n / n^2 = 1/n \to 0" />；但 <M t="n^2 \ne o(n^2)" />，因為比值永遠是 1。

#### 常見的成長率

常見函數由慢到快的順序（<M t="k \ge 2" /> 是整數、<M t="0 < \varepsilon < 1" />）：

<M d t="1 < \log n < \log^k n < n^{\varepsilon} < n < n \log n < n^2 < n^3 < 2^n < 3^n < n! < n^n" />

這裡的「<M t="<" />」是指左邊比右邊**嚴格**慢，也就是 <M t="f < g" /> 代表 <M t="f = o(g)" />（見上一段）。把其中幾個畫在同一張圖上，差距一目了然：

漸近比較的是「**最後**」誰比較大，不是眼前。例如 <M t="n \log_2 n" /> 和 <M t="n^{1.1}" />：<M t="n = 2^{20}" />（約一百萬）時前者還是後者的 5 倍，到 <M t="n = 2^{60}" /> 才被追過；但不管多晚，<M t="n^{1.1}" /> 最後一定會贏，所以 <M t="n \log n = o(n^{1.1})" />。

#### 比大小時常用的事實

**1. 對數的底數不重要。** 換底公式 <M t="\log_2 n = \dfrac{\log_{10} n}{\log_{10} 2}" />，而 <M t="\dfrac{1}{\log_{10} 2} \approx 3.32" /> 只是一個常數，所以 <M t="\log_2 n = \Theta(\log_{10} n)" />。這就是為什麼寫複雜度時通常只寫 <M t="\log n" />，不寫底數。

**2. 指數的底數很重要。** <M t="4^n = 2^n \cdot 2^n" />，所以 <M t="4^n / 2^n = 2^n" />，這個比值會無限長大，不是常數，因此 <M t="4^n \ne O(2^n)" />。但指數上加一個常數只是乘一個常數：<M t="2^{n+1} = 2 \cdot 2^n = \Theta(2^n)" />。

**3. 任何多項式最後都贏過任何 log 的次方**：<M t="\log^k n = o(n^{\varepsilon})" />。例如 <M t="\log^{100} n" /> 一開始比 <M t="\sqrt{n}" /> 大得多，但最後還是比較小。

**4. <M t="\log(n!) = \Theta(n \log n)" />。** 分成上界和下界兩步：

- **上界**：<M t="n! = 1 \cdot 2 \cdot 3 \cdots n" /> 的每一個因數都不超過 <M t="n" />，共 <M t="n" /> 個，所以 <M t="n! \le n^n" />，取 log 得 <M t="\log(n!) \le n \log n" />。
- **下界**：只看後半段 <M t="\frac{n}{2}+1, \ldots, n" /> 這 <M t="n/2" /> 個因數，每一個都至少 <M t="n/2" />；前半段的因數都 <M t="\ge 1" />，丟掉只會讓乘積變小。所以 <M t="n! \ge (n/2)^{n/2}" />，取 log 得 <M t="\log(n!) \ge \frac{n}{2} \log \frac{n}{2}" />，這是 <M t="\Omega(n \log n)" />。

上下界同級，所以 <M t="\log(n!) = \Theta(n \log n)" />。

**5. 不知道從何比起時，先取 log。** <M t="\log" /> 是遞增函數，<M t="f" /> 比 <M t="g" /> 大就等於 <M t="\log f" /> 比 <M t="\log g" /> 大，而取 log 會把次方變成乘法，比較好比。例如比較 <M t="n^{\log n}" /> 和 <M t="2^n" />（log 以 2 為底）：

<M d t="\log_2 \left(n^{\log n}\right) = (\log n)^2, \qquad \log_2 (2^n) = n" />

<M t="(\log n)^2" /> 比 <M t="n" /> 慢（事實 3），而且兩者的差 <M t="n - (\log n)^2" /> 會無限長大，所以 <M t="n^{\log n} = o(2^n)" />。

注意：取 log 之後要看的是**差距會不會無限長大**，不是兩者同不同級。例如 <M t="\log(2^n) = n" />、<M t="\log(3^n) \approx 1.58n" />，取 log 後都是 <M t="\Theta(n)" />；但差距 <M t="0.58n" /> 會無限長大，所以 <M t="2^n = o(3^n)" />，兩者並不同級。

### 遞迴與遞迴關係式

遞迴程式的時間，可以寫成**遞迴關係式**：<M t="T(n)" /> ＝ 子問題的時間總和 ＋ 這一層自己做的事。寫的時候要回答三個問題：

1. 遞迴呼叫了**幾次**？
2. 每次呼叫的**問題大小**是多少？
3. 除了遞迴之外，這一層**自己**做了多少事？

以合併排序為例：

```
mergeSort(A, n):
    if n <= 1: return            // 一個元素已經排好
    mergeSort(左半, n/2)          // 1、2：呼叫兩次，每次大小 n/2
    mergeSort(右半, n/2)
    merge(左半, 右半)             // 3：合併兩個排好的半段，Θ(n)
```

三個答案分別是「兩次」、「<M t="n/2" />」、「<M t="\Theta(n)" />」，所以

<M d t="T(n) = 2T(n/2) + \Theta(n)" />

常見的幾個：

| 程式 | 遞迴關係式 | 解 |
|---|---|---|
| 二分搜尋 | <M t="T(n) = T(n/2) + \Theta(1)" /> | <M t="\Theta(\log n)" /> |
| 合併排序 | <M t="T(n) = 2T(n/2) + \Theta(n)" /> | <M t="\Theta(n \log n)" /> |
| 河內塔 | <M t="T(n) = 2T(n-1) + 1" /> | <M t="2^n - 1" /> |
| 直接遞迴的費氏數列 | <M t="T(n) = T(n-1) + T(n-2) + \Theta(1)" /> | <M t="\Theta(\varphi^n)" />，<M t="\varphi = \frac{1+\sqrt{5}}{2} \approx 1.618" /> |
| 遞迴求 <M t="n!" /> | <M t="T(n) = T(n-1) + \Theta(1)" /> | <M t="\Theta(n)" /> |

解遞迴關係式有三種方法。

#### 1. 展開（迭代）法

把式子裡的 <M t="T(\cdot)" /> 一直用定義代換，直到看出規律。以河內塔 <M t="T(n) = 2T(n-1) + 1" />、<M t="T(1) = 1" /> 為例：

<M d t="\begin{aligned} T(n) &= 2T(n-1) + 1 \\ &= 2\,[\,2T(n-2) + 1\,] + 1 = 4T(n-2) + 2 + 1 \\ &= 4\,[\,2T(n-3) + 1\,] + 2 + 1 = 8T(n-3) + 4 + 2 + 1 \end{aligned}" />

規律是：代換 <M t="k" /> 次之後，前面是 <M t="2^k T(n-k)" />，後面是 <M t="1 + 2 + \cdots + 2^{k-1}" />。一直代到 <M t="T(1)" />，也就是 <M t="k = n - 1" />：

<M d t="T(n) = 2^{n-1} T(1) + (1 + 2 + \cdots + 2^{n-2})" />

括號裡是等比級數：<M t="1 + 2 + \cdots + 2^{m} = 2^{m+1} - 1" />（例如 <M t="1 + 2 + 4 = 7 = 8 - 1" />），這裡 <M t="m = n - 2" />，所以括號等於 <M t="2^{n-1} - 1" />。再代入 <M t="T(1) = 1" />：

<M d t="T(n) = 2^{n-1} + 2^{n-1} - 1 = 2^n - 1" />

#### 2. 遞迴樹

把每一次呼叫畫成一個節點，節點裡寫「這一層自己做的事」，再一層一層加總。以 <M t="T(n) = 2T(n/2) + n" /> 為例：

- 第 0 層：1 個節點，問題大小 <M t="n" />，自己做 <M t="n" />。
- 第 1 層：2 個節點，每個大小 <M t="n/2" />，各做 <M t="n/2" />，合計 <M t="2 \times \frac{n}{2} = n" />。
- 第 <M t="i" /> 層：<M t="2^i" /> 個節點，每個大小 <M t="n/2^i" />，合計 <M t="2^i \times \frac{n}{2^i} = n" />。

問題大小每層減半，減到 1 需要 <M t="\log_2 n" /> 次，所以共有 <M t="\log_2 n + 1" /> 層，每層都是 <M t="n" />：

<Figure no="1-4" caption="T(n) = 2T(n/2) + n 的遞迴樹：子問題的數量加倍、大小減半，兩者相乘每層都是 n。共 log₂ n + 1 層，總和 Θ(n log n)。">
  <RecursionTree />
</Figure>

<M d t="T(n) = n \cdot (\log_2 n + 1) = \Theta(n \log n)" />

#### 3. 主定理

形如 <M t="T(n) = aT(n/b) + f(n)" /> 的式子可以直接套用，見下一節。

#### 遞迴也會用到空間

每一層還沒結束的呼叫都佔一格堆疊，所以遞迴的**深度**就是額外空間的下限。直接遞迴求 <M t="n!" /> 要一路呼叫到 <M t="n = 1" />，深度是 <M t="n" />，需要 <M t="\Theta(n)" /> 的堆疊空間；遞迴的二分搜尋每次減半，深度只有 <M t="\Theta(\log n)" />。

### 主定理

主定理是「遞迴樹」的速算版。它適用的形式是

<M d t="T(n) = a\,T(n/b) + f(n), \qquad a \ge 1,\ b > 1" />

三個參數的意思：**<M t="a" />** 是每次呼叫自己幾次、**<M t="b" />** 是問題每次縮小成幾分之一、**<M t="f(n)" />** 是每一層自己做的事。例如合併排序 <M t="a = 2" />、<M t="b = 2" />、<M t="f(n) = n" />。

#### n^(log_b a) 是什麼

畫出這個式子的遞迴樹：

- 問題大小每層變成 <M t="1/b" />，從 <M t="n" /> 縮到 1 需要 <M t="\log_b n" /> 層。
- 節點數每層乘以 <M t="a" />，所以最底層有 <M t="a^{\log_b n}" /> 個葉子。

這個數可以換一個寫法：<M t="a^{\log_b n} = n^{\log_b a}" />（兩邊取 <M t="\log_b" />，都是 <M t="\log_b a \cdot \log_b n" />）。每個葉子做 <M t="\Theta(1)" />，所以**最底層的總成本是 <M t="\Theta(n^{\log_b a})" />**。

另一頭，**最上層（根）的成本是 <M t="f(n)" />**。主定理就是在問：整棵樹的總成本由誰決定？答案取決於 <M t="f(n)" /> 和 <M t="n^{\log_b a}" /> 誰比較大，而且要大「**多項式倍**」，也就是比值至少是 <M t="n^{\varepsilon}" />（某個 <M t="\varepsilon > 0" />，例如 <M t="n^{0.1}" />）這個等級，光差一個 <M t="\log n" /> 倍不算。

| 情況 | 條件 | 結果 |
|---|---|---|
| 1. 葉子主導 | <M t="f(n) = O(n^{\log_b a - \varepsilon})" />，<M t="\varepsilon > 0" /> | <M t="T(n) = \Theta(n^{\log_b a})" /> |
| 2. 每層差不多 | <M t="f(n) = \Theta(n^{\log_b a})" /> | <M t="T(n) = \Theta(n^{\log_b a} \log n)" /> |
| 3. 根主導 | <M t="f(n) = \Omega(n^{\log_b a + \varepsilon})" />，<M t="\varepsilon > 0" />，而且 <M t="a f(n/b) \le c f(n)" />、<M t="c < 1" /> | <M t="T(n) = \Theta(f(n))" /> |

三種情況，就是遞迴樹每層成本的三種走勢：

- **情況 1**：<M t="f" /> 比葉子小多項式倍，越往下每層越多，總和由最底層決定。
- **情況 2**：每層差不多，總和是「一層的成本 × 層數」，層數是 <M t="\log n" />，所以多乘一個 <M t="\log n" />。
- **情況 3**：<M t="f" /> 比葉子大多項式倍，越往下越少，總和由根決定。額外的條件 <M t="a f(n/b) \le c f(n)" />（**正規條件**）就是在確認「下一層的總成本真的比這一層小一個固定比例」；考試常見的 <M t="f(n)" /> 都滿足，但寫證明題時要寫出來。

情況 2 的**延伸**：若 <M t="f(n) = \Theta(n^{\log_b a} \log^k n)" />，<M t="k \ge 0" />，則 <M t="T(n) = \Theta(n^{\log_b a} \log^{k+1} n)" />。<M t="k = 0" /> 時就是原本的情況 2。

#### 套用的步驟

1. 讀出 <M t="a" />、<M t="b" />、<M t="f(n)" />。
2. 算出 <M t="n^{\log_b a}" />。
3. 比較 <M t="f(n)" /> 和 <M t="n^{\log_b a}" />：誰大？大多項式倍嗎？
4. 選情況、寫答案；情況 3 記得檢查正規條件。

**例 1：<M t="T(n) = 9T(n/3) + n" />**

1. <M t="a = 9" />、<M t="b = 3" />、<M t="f(n) = n" />。
2. <M t="\log_3 9 = 2" />（因為 <M t="3^2 = 9" />），所以 <M t="n^{\log_b a} = n^2" />。
3. <M t="f(n) = n" /> 比 <M t="n^2" /> 小，比值 <M t="n / n^2 = n^{-1}" />，小了多項式倍（取 <M t="\varepsilon = 1" />）。
4. 情況 1：<M t="T(n) = \Theta(n^2)" />。

**例 2：<M t="T(n) = T(2n/3) + 1" />**

1. 問題每次變成 <M t="2/3" />，也就是除以 <M t="3/2" />：<M t="a = 1" />、<M t="b = 3/2" />、<M t="f(n) = 1" />。
2. <M t="\log_{3/2} 1 = 0" />，所以 <M t="n^{\log_b a} = n^0 = 1" />。
3. <M t="f(n) = 1 = \Theta(1)" />，兩者同級。
4. 情況 2：<M t="T(n) = \Theta(1 \cdot \log n) = \Theta(\log n)" />。

**例 3：<M t="T(n) = 3T(n/4) + n \log n" />**

1. <M t="a = 3" />、<M t="b = 4" />、<M t="f(n) = n \log n" />。
2. <M t="\log_4 3 \approx 0.793" />，所以 <M t="n^{\log_b a} \approx n^{0.793}" />。
3. <M t="f(n) = n \log n \ge n^{1}" />，比 <M t="n^{0.793}" /> 大了至少 <M t="n^{0.2}" /> 倍，是多項式倍。
4. 檢查正規條件：

<M d t="a f(n/b) = 3 \cdot \frac{n}{4} \log \frac{n}{4} = \frac{3}{4}\, n \,(\log n - 2) \le \frac{3}{4}\, n \log n = \frac{3}{4} f(n)" />

　　<M t="c = 3/4 < 1" />，成立。情況 3：<M t="T(n) = \Theta(n \log n)" />。

#### 主定理不能用的情況

**不是「除以 <M t="b" />」的形式**：例如 <M t="T(n) = T(n-1) + n" />，問題每次只減 1，用展開法：<M t="T(n) = n + (n-1) + \cdots + 1 = \Theta(n^2)" />。

**差的不是多項式倍**：例如 <M t="T(n) = 2T(n/2) + n / \log n" />。<M t="a = 2" />、<M t="b = 2" />，<M t="n^{\log_b a} = n" />；<M t="f(n) = n / \log n" /> 比 <M t="n" /> 小，但只小了 <M t="\log n" /> 倍，不到任何 <M t="n^{\varepsilon}" /> 倍，所以不是情況 1；它也不是 <M t="\Theta(n)" />，所以不是情況 2。三種情況都不符合，只好回到遞迴樹自己加（設 <M t="n = 2^m" />，log 以 2 為底）：

- 第 <M t="i" /> 層有 <M t="2^i" /> 個節點，每個大小 <M t="n/2^i" />，各做 <M t="\dfrac{n/2^i}{\log(n/2^i)}" />。
- <M t="\log(n/2^i) = m - i" />，所以這一層合計 <M t="2^i \cdot \dfrac{n/2^i}{m - i} = \dfrac{n}{m - i}" />。
- <M t="i" /> 從 0 到 <M t="m - 1" />，分母 <M t="m - i" /> 從 <M t="m" /> 走到 1：

<M d t="T(n) \approx n \left( \frac{1}{m} + \frac{1}{m-1} + \cdots + \frac{1}{1} \right) = n H_m" />

括號是調和數 <M t="H_m" />，約等於 <M t="\ln m" />，也就是 <M t="\Theta(\log m)" />。代回 <M t="m = \log n" />，得到 <M t="T(n) = \Theta(n \log \log n)" />。

### 常見陷阱

- **<M t="O" /> 不是「剛好」**：<M t="n = O(n^2)" /> 是對的，只是不夠緊。題目問「最緊的上界」時要寫 <M t="\Theta" /> 等級的答案。
- **最差情況和平均情況是不同的函數**，各自都可以用 <M t="O" />、<M t="\Omega" />、<M t="\Theta" /> 描述。不要把「<M t="O" /> 等於最差、<M t="\Omega" /> 等於最佳」混為一談。
- **遞迴呼叫兩次和一次差很多**：`return g(n/2) + g(n/2)` 是 <M t="2T(n/2)" />，先算一次再乘 2 只有 <M t="T(n/2)" />。
- **證明 <M t="O" /> 要寫出 <M t="c" /> 和 <M t="n_0" />**：只說「因為最高次項是 <M t="n^2" />」在證明題會被扣分。
- **情況 3 要檢查正規條件**（<M t="a f(n/b) \le c f(n)" />）。

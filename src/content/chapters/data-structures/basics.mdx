### 演算法與效能分析

**演算法**（algorithm）是解決問題的有限步驟。課本常列出它必須滿足的五個性質：

| 性質 | 意思 |
|---|---|
| 輸入（input） | 零個或多個由外部提供的資料 |
| 輸出（output） | 至少產生一個結果 |
| 明確性（definiteness） | 每一步都清楚、沒有歧義 |
| 有限性（finiteness） | 一定會在有限步之後結束 |
| 有效性（effectiveness） | 每一步都基本到可以用紙筆在有限時間內做完 |

「程式」不一定滿足有限性：作業系統本身就是一個不會主動結束的程式，所以它不是演算法。這是選擇題常見的陷阱。

分析一個演算法，看兩件事：

- **時間複雜度**：執行需要多少步，表示成輸入大小 <M t="n" /> 的函數。
- **空間複雜度**：除了輸入本身之外，還需要多少額外記憶體（變數、陣列、遞迴呼叫的堆疊）。

考試常要求**步驟計數**：算出某一行敘述被執行幾次。方法是由內往外，把每一層迴圈的次數加總。

```
for i = 1 to n
    for j = i to n
        x = x + 1
```

<M t="i = 1" /> 時內層跑 <M t="n" /> 次，<M t="i = 2" /> 時跑 <M t="n-1" /> 次，……，<M t="i = n" /> 時跑 1 次。把每一組 <M t="(i, j)" /> 畫成一格，執行過的格子剛好排成一個三角形：

<Figure no="1-1" caption="n = 6 時，第 i 列有 n − i + 1 個實心格。實心格的總數就是 x = x + 1 的執行次數。">
  <LoopTriangle />
</Figure>

<M d t="\sum_{i=1}^{n} (n - i + 1) = n + (n-1) + \cdots + 1 = \frac{n(n+1)}{2} = \Theta(n^2)" />

另一種常見的迴圈是「每次乘以 2」：

```
i = 1
while i < n
    i = i * 2
```

<M t="i" /> 依序是 1, 2, 4, …，第 <M t="k" /> 次檢查時 <M t="i = 2^{k-1}" />。迴圈在 <M t="i \ge n" /> 時停止，所以本體執行 <M t="\lceil \log_2 n \rceil" /> 次（<M t="n \ge 1" />）。看到變數被乘或除以常數，答案就跟 <M t="\log" /> 有關。

### 漸近符號

精確的步驟數（例如 <M t="3n^2 + 5n + 7" />）太瑣碎，我們只在意 <M t="n" /> 很大時的**成長率**。漸近符號就是用來描述成長率的語言：

| 符號 | 定義 | 直覺 |
|---|---|---|
| <M t="f(n) = O(g(n))" /> | 存在常數 <M t="c > 0" /> 與 <M t="n_0" />，使所有 <M t="n \ge n_0" /> 都有 <M t="f(n) \le c\,g(n)" /> | 上界：不會比 <M t="g" /> 長得快 |
| <M t="f(n) = \Omega(g(n))" /> | 存在常數 <M t="c > 0" /> 與 <M t="n_0" />，使所有 <M t="n \ge n_0" /> 都有 <M t="f(n) \ge c\,g(n)" /> | 下界：至少和 <M t="g" /> 一樣快 |
| <M t="f(n) = \Theta(g(n))" /> | 同時 <M t="f = O(g)" /> 且 <M t="f = \Omega(g)" /> | 同一個成長率 |
| <M t="f(n) = o(g(n))" /> | 對**每個** <M t="c > 0" /> 都存在 <M t="n_0" />，使 <M t="n \ge n_0" /> 時 <M t="f(n) < c\,g(n)" /> | 嚴格比 <M t="g" /> 慢：<M t="f(n)/g(n) \to 0" /> |
| <M t="f(n) = \omega(g(n))" /> | 對每個 <M t="c > 0" /> 都存在 <M t="n_0" />，使 <M t="n \ge n_0" /> 時 <M t="f(n) > c\,g(n)" /> | 嚴格比 <M t="g" /> 快：<M t="f(n)/g(n) \to \infty" /> |

定義裡的 <M t="n_0" /> 很重要：<M t="n" /> 小的時候 <M t="f" /> 可以比 <M t="c\,g" /> 大，只要從某一點之後一直不超過就好。

<Figure no="1-2" caption="f(n) = n² + 6n + 10 在 n 小的時候比 2n² 大，但從 n₀ = 3 + √19 ≈ 7.4 之後一直在下方，所以 f(n) = O(n²)（c = 2）。">
  <BigODefinition />
</Figure>

另一個例子：<M t="3n^2 + 5n + 7 = \Theta(n^2)" />。取 <M t="c = 15" />、<M t="n_0 = 1" />，因為 <M t="n \ge 1" /> 時 <M t="3n^2 + 5n + 7 \le 3n^2 + 5n^2 + 7n^2 = 15n^2" />，所以是 <M t="O(n^2)" />；又 <M t="3n^2 + 5n + 7 \ge 3n^2" />，所以是 <M t="\Omega(n^2)" />。

常見函數由慢到快的順序（<M t="k \ge 2" /> 是整數、<M t="0 < \varepsilon < 1" />）：

<M d t="1 < \log n < \log^k n < n^{\varepsilon} < n < n \log n < n^2 < n^3 < 2^n < 3^n < n! < n^n" />

把它們畫在同一張圖上，差距一目了然：

<Figure no="1-3" caption="n 只到 20，2ⁿ 在 n ≈ 8.2 就超過 300，n² 在 n ≈ 17.3；n log n 到 n = 20 才約 86，而 n 和 log n 幾乎貼著底部。">
  <GrowthChart />
</Figure>

幾個比大小時常用的事實：

- **對數的底數不重要**：<M t="\log_2 n = \dfrac{\log_{10} n}{\log_{10} 2}" />，只差一個常數倍，所以 <M t="\log_2 n = \Theta(\log_{10} n)" />，通常直接寫 <M t="\log n" />。
- **指數的底數很重要**：<M t="4^n = 2^n \cdot 2^n" />，比 <M t="2^n" /> 快得多，<M t="4^n \ne O(2^n)" />。但 <M t="2^{n+1} = 2 \cdot 2^n = \Theta(2^n)" />。
- **任何多項式都贏過任何 log 的次方**：<M t="\log^k n = o(n^{\varepsilon})" />，例如 <M t="\log^{100} n" /> 最後還是比 <M t="\sqrt{n}" /> 小。
- **<M t="\log(n!) = \Theta(n \log n)" />**：上界 <M t="\log(n!) \le \log(n^n) = n \log n" />；下界只看後半段 <M t="n/2" /> 個因數，每個至少 <M t="n/2" />，所以 <M t="\log(n!) \ge \frac{n}{2} \log \frac{n}{2}" />。
- **比較兩個函數不知道從何下手時，取 log 再比**：例如 <M t="n^{\log n} = 2^{(\log n)^2}" />，而 <M t="2^n" /> 的指數是 <M t="n" />；<M t="(\log n)^2" /> 比 <M t="n" /> 慢，所以 <M t="n^{\log n} = o(2^n)" />。

### 遞迴與遞迴關係式

遞迴程式的時間，可以寫成**遞迴關係式**：<M t="T(n)" /> ＝ 子問題的時間總和 ＋ 這一層自己做的事。寫的時候注意三件事：遞迴呼叫了**幾次**、每次的**問題大小**、這一層**額外**做了多少。

| 程式 | 遞迴關係式 | 解 |
|---|---|---|
| 二分搜尋 | <M t="T(n) = T(n/2) + \Theta(1)" /> | <M t="\Theta(\log n)" /> |
| 合併排序 | <M t="T(n) = 2T(n/2) + \Theta(n)" /> | <M t="\Theta(n \log n)" /> |
| 河內塔 | <M t="T(n) = 2T(n-1) + 1" /> | <M t="2^n - 1" /> |
| 直接遞迴的費氏數列 | <M t="T(n) = T(n-1) + T(n-2) + \Theta(1)" /> | <M t="\Theta(\varphi^n)" />，<M t="\varphi = \frac{1+\sqrt{5}}{2} \approx 1.618" /> |
| 遞迴求 <M t="n!" /> | <M t="T(n) = T(n-1) + \Theta(1)" /> | <M t="\Theta(n)" /> |

解遞迴關係式有三種方法：

**1. 展開（迭代）法**：一直代入，直到看出規律。以河內塔為例，<M t="T(1) = 1" />：

<M d t="\begin{aligned} T(n) &= 2T(n-1) + 1 \\ &= 4T(n-2) + 2 + 1 \\ &= \cdots \\ &= 2^{n-1} T(1) + 2^{n-2} + \cdots + 2 + 1 \\ &= 2^n - 1 \end{aligned}" />

**2. 遞迴樹**：把每一層的成本畫出來再加總。以 <M t="T(n) = 2T(n/2) + n" /> 為例，第 <M t="i" /> 層有 <M t="2^i" /> 個子問題、每個大小 <M t="n/2^i" />，所以每層成本都是 <M t="n" />：

<Figure no="1-4" caption="T(n) = 2T(n/2) + n 的遞迴樹：子問題的數量加倍、大小減半，兩者相乘每層都是 n。共 log₂ n + 1 層，總和 Θ(n log n)。">
  <RecursionTree />
</Figure>

**3. 主定理**：形如 <M t="T(n) = aT(n/b) + f(n)" /> 的式子可以直接套用，見下一節。

遞迴也會用到空間：每一層呼叫都佔一格堆疊，所以遞迴的**深度**就是額外空間的下限。直接遞迴的 <M t="n!" /> 需要 <M t="\Theta(n)" /> 的堆疊空間，二分搜尋只需要 <M t="\Theta(\log n)" />。

### 主定理

對 <M t="T(n) = aT(n/b) + f(n)" />（<M t="a \ge 1" />、<M t="b > 1" />），把 <M t="f(n)" /> 和 <M t="n^{\log_b a}" /> 比大小。<M t="n^{\log_b a}" /> 是遞迴樹最底層「葉子」的總成本，<M t="f(n)" /> 是根節點的成本：

| 情況 | 條件 | 結果 |
|---|---|---|
| 1. 葉子主導 | <M t="f(n) = O(n^{\log_b a - \varepsilon})" />，<M t="\varepsilon > 0" /> | <M t="T(n) = \Theta(n^{\log_b a})" /> |
| 2. 每層差不多 | <M t="f(n) = \Theta(n^{\log_b a})" /> | <M t="T(n) = \Theta(n^{\log_b a} \log n)" /> |
| 3. 根主導 | <M t="f(n) = \Omega(n^{\log_b a + \varepsilon})" />，<M t="\varepsilon > 0" />，而且 <M t="a f(n/b) \le c f(n)" />、<M t="c < 1" /> | <M t="T(n) = \Theta(f(n))" /> |

三種情況其實就是遞迴樹每層成本的三種走勢：

<Figure no="1-5" caption="以第 0 層的成本為單位：每層成本遞增時由最底層（葉子）決定，每層一樣時乘上層數，遞減時由第 0 層（根）決定。">
  <MasterCases />
</Figure>

情況 2 的**延伸**：若 <M t="f(n) = \Theta(n^{\log_b a} \log^k n)" />，<M t="k \ge 0" />，則 <M t="T(n) = \Theta(n^{\log_b a} \log^{k+1} n)" />。

例：

- <M t="T(n) = 9T(n/3) + n" />：<M t="n^{\log_3 9} = n^2" />，<M t="f(n) = n" /> 小了多項式倍 → 情況 1，<M t="\Theta(n^2)" />。
- <M t="T(n) = T(2n/3) + 1" />：<M t="a = 1" />、<M t="b = 3/2" />，<M t="n^{\log_b a} = n^0 = 1" />，<M t="f(n) = \Theta(1)" /> → 情況 2，<M t="\Theta(\log n)" />。
- <M t="T(n) = 3T(n/4) + n \log n" />：<M t="n^{\log_4 3} \approx n^{0.793}" />，<M t="f(n)" /> 大了多項式倍；而且 <M t="3 \cdot \frac{n}{4} \log \frac{n}{4} \le \frac{3}{4} n \log n" /> → 情況 3，<M t="\Theta(n \log n)" />。

**主定理不能用的情況**：

- 不是「除以 <M t="b" />」的形式，例如 <M t="T(n) = T(n-1) + n" />（用展開法：<M t="\Theta(n^2)" />）。
- <M t="f(n)" /> 和 <M t="n^{\log_b a}" /> 差的不是**多項式**倍。例如 <M t="T(n) = 2T(n/2) + n/\log n" />：<M t="f(n)" /> 比 <M t="n" /> 小，但只小了 <M t="\log n" /> 倍，不屬於任何一種情況。用遞迴樹算，第 <M t="i" /> 層成本是 <M t="\frac{n}{\log n - i}" />，加總得 <M t="\Theta(n \log \log n)" />。

### 常見陷阱

- **<M t="O" /> 不是「剛好」**：<M t="n = O(n^2)" /> 是對的，只是不夠緊。題目問「最緊的上界」時要寫 <M t="\Theta" /> 等級的答案。
- **最差情況和平均情況是不同的函數**，各自都可以用 <M t="O" />、<M t="\Omega" />、<M t="\Theta" /> 描述。不要把「<M t="O" /> 等於最差、<M t="\Omega" /> 等於最佳」混為一談。
- **遞迴呼叫兩次和一次差很多**：`return g(n/2) + g(n/2)` 是 <M t="2T(n/2)" />，先算一次再乘 2 只有 <M t="T(n/2)" />。
- **情況 3 要檢查正規條件**（<M t="a f(n/b) \le c f(n)" />）；考試常見的 <M t="f(n)" /> 都滿足，但寫證明題時要寫出來。
